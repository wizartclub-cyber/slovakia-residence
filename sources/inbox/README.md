# sources/inbox — файли, що чекають на підтвердження адреси

Сюди складаються документи, які власник зберіг вручну, але для яких ще НЕ
встановлено точну офіційну адресу завантаження. Без адреси файл не можна
внести в реєстр: контрольна сума без джерела не є доказом.

Щойно адресу підтверджено — файл переїжджає в `sources/snapshots/<id>.<ext>`,
у реєстр додається запис, і виконується `python3 scripts/download_and_hash.py --local`.

Самі файли не потрапляють у git (див. `.gitignore`).
