# Як почати роботу з Claude Code (перший запуск)

## Один раз
1. Встанови Node.js (LTS) з nodejs.org і pnpm: у Terminal `npm install -g pnpm`.
2. У Terminal: `cd ~/Documents/Codex/slovakia-residence` → `git init` (створює історію змін) → `claude` (запускає Claude Code).

## Перший промпт (скопіювати повністю)

```
Прочитай CLAUDE.md, SNAPSHOT.md і PLAN.md. Ми починаємо Slice 0.

Перед тим як щось робити, напиши мені 3 рядки: що зробиш, які файли створиш, які команди запустиш. Пояснюй кожну команду простою українською — я не розробник.

Правила на цю сесію:
- Тільки Slice 0. Не переходь до Slice 1.
- Стек зафіксовано в CLAUDE.md §3. Нова залежність — спитай.
- Не чіпай document-registry-*.yaml, SOURCE_AUDIT*, spec, sources/.
- Наприкінці — «Заверши сесію за правилами CLAUDE.md».

Почни з плану, чекай мого «ок».
```

## Тригери, які варто знати
- «Заверши сесію за правилами CLAUDE.md» — агент оновить NOTES.md, SNAPSHOT.md, PLAN.md і зробить коміт.
- «Покажи DoD» — агент дає 3–5 рядків, що перевірити руками в браузері.
- «Стоп, поясни» — зупиняє і пояснює, що зараз відбувається.

## Наступні сесії
Промпт: `Прочитай CLAUDE.md і SNAPSHOT.md. Продовжуємо Slice N. План на 3 рядки, чекай «ок».`
